# Гардероб

Подбор образов из своего гардероба по температуре, слоям и погоде. Работает как сайт и как приложение на телефоне (PWA), есть осень и зима.

Страница: <https://iheartbeard.github.io/wardrobe-fits/>

## Как это работает

- Выбери вещь, и карточки, которые не подходят по температуре, слоям или погоде, станут недоступными.
- Жёлтым выделены вещи из готовых образов, синим вещи, подходящие по цвету к выбранному.
- Кнопка «5 образов под выбранную обувь» подбирает пять разных образов с разбросом по температуре.
- Полоса «Сейчас» берёт ощущаемую температуру и дождь по твоему местоположению (Open-Meteo, название места из BigDataCloud).

## Капсула в поездку

Отдельное приложение на той же базе: <https://iheartbeard.github.io/wardrobe-fits/trip/>. Указываешь место и даты (или температуры вручную) и размер багажа, и страница собирает небольшую капсулу, в которой вещи сочетаются друг с другом и закрывают погоду каждого дня. Вещи можно закрепить или убрать, есть план по дням и чек-лист сборов. Прогноз берётся из Open-Meteo, если поездка в ближайшие 16 дней, иначе погода тех же дат прошлого года. Летние вещи для поездок лежат в `js/trip/summer.js`.

```
trip/                 страница, манифест, service worker и иконки капсулы
js/trip/capsule.js    подбор капсулы и плана по дням (без DOM)
js/trip/forecast.js   место и погода на даты поездки
js/trip/summer.js     летние вещи для поездок
js/trip/app.js        интерфейс капсулы
```

## Структура

```
index.html            разметка страницы
css/styles.css        стили (светлая и тёмная темы, телефон)
js/main.js            точка входа сайта
js/main.artifact.js   точка входа версии для артефакта (без погоды)
js/config.js          константы: слоты, фильтры, ключи хранилища
js/model.js           модель сезона: маски температур, комбинации, готовые образы
js/selection.js       доступность карточек и подсветка при текущем выборе
js/suggest.js         «5 образов» и случайное сочетание
js/weather.js         текущая погода и местоположение
js/lib/               температурная шкала и оценка сочетания цветов
js/data/              вещи по сезонам, готовые образы, подборка из книги Васо
js/ui/                шаблоны и обработчики страницы
sw.js                 service worker (офлайн)
tools/                локальный сервер и сборка одностраничной версии
tests/                модульные тесты и сквозная проверка поведения
```

## Как добавить вещь

Вещи лежат в `js/data/autumn.js`. Для зимы `js/data/winter.js` берёт нужные вещи из осенних данных по id и переопределяет диапазоны температур. Правило такое: вещь попадает на страницу сезона только если отмечена на этот сезон, а её диапазон температур действует внутри сезона.

Поля вещи:

| Поле                                                   | Значение                                                                                            |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------------- |
| `id`, `name`, `colorName`, `hex`, `group`              | идентификатор, название, описание цвета, цвет, группа на странице                                   |
| `minTemp`, `maxOverLight`, `maxOverHeavy`, `warmBelow` | куртка: нижняя граница, верхняя над лёгким и плотным слоем, ниже этой температуры нужен тёплый слой |
| `kinds`, `ban`, `noRain`                               | куртка: какие слои можно или нельзя под неё, не годится под дождь                                   |
| `kind`, `outer`, `under`, `weight`, `warm`             | слой: тип, диапазон как верхнего слоя и под курткой, вес от 0 до 3, можно ли под куртку в холод     |
| `range`                                                | низ, головной убор, шарф: допустимые температуры                                                    |
| `dry`, `rain`                                          | обувь: диапазоны для сухой и дождливой погоды                                                       |

Готовые образы лежат в `js/data/looks.js`. Личные сочетания из книги Васо Санцо добавляются в `js/data/wada.js`.

## Разработка

```sh
npm install
npm start            # http://localhost:8080 (ES-модули не открываются с file://)
npm run lint         # ESLint
npm run format       # Prettier
npm test             # модульные тесты
npm run test:e2e     # сквозная проверка в браузере (нужен playwright)
npm run build:single # dist/artifact.html: вся страница одним файлом
```

Сквозная проверка сравнивает поведение страницы (клики по карточкам, полосам, погоде и образам) с `tests/e2e/golden.json`. Если поведение изменено намеренно, обнови эталон: `UPDATE_GOLDEN=1 npm run test:e2e`.
